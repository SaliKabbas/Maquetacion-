Nombre del Sistema: GlobalFit Core UI

Descripción del Proyecto:

GlobalFit Core UI es la interfaz visual y maqueta interactiva diseñada para la gestión integral del gimnasio Global Fit. Este prototipo permite explorar la experiencia de usuario y la estructura frontend del software de administración, ofreciendo una visualización clara y navegable de los procesos operativos clave del establecimiento.
El sistema está estructurado mediante un diseño modular que facilita el control administrativo, permitiendo interactuar con las siguientes secciones principales:
Módulo Principal (Dashboard): Panel de control central que ofrece una vista general de métricas clave, incluyendo socios activos, ingresos mensuales, membresías próximas a vencer y el registro de asistencias del día.
Módulo de Socios: Sección destinada a la visualización y administración del directorio de clientes y sus respectivos estados.
Módulo de Membresías: Apartado para consultar y gestionar los diferentes planes de suscripción disponibles en el gimnasio.
Módulo de Entrenadores: Espacio interactivo para visualizar el staff de entrenadores, con opciones simuladas para agregar y editar perfiles.
Módulo de Inventario: Control visual de la mercancía y productos que ofrece el gimnasio a la venta.
Módulo de Configuración: Panel de ajustes generales para personalizar la apariencia y el comportamiento de la interfaz del sistema.

Nota: En esta etapa actual, el proyecto corresponde a una maquetación frontend. Las vistas y la navegación son completamente interactivas para fines de demostración, estructuración y validación de requerimientos, preparadas para su futura integración con el backend y la base de datos.

Tecnologías Utilizadas
Para el desarrollo y diseño de esta maqueta se han empleado las siguientes tecnologías:

HTML5: Estructuración semántica de las vistas, tablas, formularios y la arquitectura general de los módulos.

CSS3: Diseño responsivo, estilos personalizados, paleta de colores corporativa y distribución visual para lograr una interfaz limpia y ordenada.

JavaScript: Interactividad del DOM, navegación dinámica entre módulos, simulación de acciones como agregar o editar, y manipulación de elementos en la interfaz.
